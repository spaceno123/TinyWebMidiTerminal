# TinyWebMidiTerminal
Tiny Midi Terminal using Web Midi Api.

Text data transfer using MIDI polyphonic key pressure of ch.11 to 15.

Run Web MIDI Terminal in a new tab: <a href="https://spaceno123.github.io/TinyWebMidiTerminal/source/index.html" target="_blank" rel="noopener noreferrer">"Launch App"</a>
